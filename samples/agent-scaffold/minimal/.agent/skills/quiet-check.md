# Skill: quiet-check

## 用途

对工作空间中已经写下的声明做一次只读的一致性核对，帮助在扩展结构后快速发现遗漏。

## 何时使用

- 刚新增或调整了 `.agent/` 下的对象文件，想知道索引是否还完整。
- 只想确认结构没有被改坏，不需要深入内容审查。

## 何时不使用

- 需要判断宿主能否加载、路由或执行 Skill —— 这属于运行时行为。
- 需要访问网络、外部服务或本工作空间以外的文件。
- 需要产生写入、修改或删除。

## 输入与输出

- 输入：工作空间根目录路径。
- 输出：一句结论。结论只描述声明层面的一致性，不给出运行时保证。

## 副作用与确认

`sideEffects` 为 `none`，因此 `confirmation` 为 `not-required`。
本 Skill 只读，不写入工作空间，也不调用外部服务。
