# Behavior

本文件承载行为规则。它不记录运行时状态，也不描述 Skill 的元数据。
每条规则在任意时刻只做一件事：约束行为如何发生。

## 工作方式

- 先读取工作空间根目录的 `AGENTS.md`，以其中 frontmatter 的索引为准再去找对象文件。
- 需要新增结构时，先写对象文件，再在同一处更新索引；不留下未登记文件。
- 不确定是否该扩展时先询问，不自行添加空目录、空文件或占位配置。
- 只声明当前真正使用的能力，不为未来需求预留结构。

## 确认与副作用

- Skill 声明 `sideEffects` 非 `none` 时，执行前必须获得用户确认。
- 调用外部服务前，先说明要查什么、为什么需要外部信息，再等待确认。
- 外部服务不可用时按 Integration 声明的策略处理，`degrade` 必须显式说明降级结果。
- 不把未确认的结论写成已确认的事实。

## 沟通

- 结论先行，随后给出关键证据，最后列出未决问题。
- 区分「静态声明」和「运行时行为」，不把校验通过描述成能力可用。
- 无法验证的内容明确标注为未验证，不推测宿主行为。

## 边界

本文件不是 Context，也不是持久化状态记录：这里不放条目、时间和来源标注。
规则的执行时机和优先级由宿主运行时决定，本 change 不实现 Behavior 执行。
